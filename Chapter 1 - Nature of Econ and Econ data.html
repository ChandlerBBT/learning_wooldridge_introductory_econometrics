The variable approve is also binary, equaling one if the loan application was approved, and zero otherwise.

data("loanapp")

loanapp %>%

loanapp %>%

  total_obs approved_ratio

  1. What is the loan approval rate for White applicants?
loanapp %>%

        total_obs = n(),

  total_obs approved_ratio

  1. Report the difference between (iii) and (ii) in percentage point terms. Does this analysis allow you to convincingly conclude that there is racial bias in mortgage application approvals? Explain.

The difference is about 20.1 percentage points. However, there are many valid reasons that a mortgage application might be rejected, and these factors might be correlated with race, we cannot use this simple comparison to conclude that there is racial bias in mortgage application approvals.
